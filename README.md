# Repro Suite (retired)

The Repro Suite apps (explainer, hub, reading, lite, desk, indexboard) have moved to Paperlit: https://bryan273.github.io/paperlit/

Every old address here now redirects to the matching Paperlit page. The full history of the old build is in this repository's git history (tag `archive-before-redirect`).

`repro/` is kept only for the run logs that Paperlit's Check page links to (`repro/index.html?job=...` and the recorded demo runs). Opened without a run it redirects too.
