How to use this site

Two things you can do with a research paper. Pick the one you need.

Check a paper: does the result hold?

  1. Pick a paper. Upload a PDF on Reproduce, or choose one under Papers.
  2. Press Start a reproduction. The agent reads the paper, writes code and runs it. It takes about 5 to 15 minutes and you can watch it live.
  3. Read the verdict. Reproduced, Not reproduced or Inconclusive, with the numbers next to what the paper reports.

If the top bar says Replay mode, no live runner is connected. You can still open any recorded run under Runs.

Learn a paper: watch a short video

  1. Open Paper Explainer. Use the button below or the link in the top bar.
  2. Paste a paper link. An arXiv link, a PDF link or a DOI works.
  3. Wait 3 to 5 minutes. You get a narrated video in English and Chinese, with every quote and number checked.

Reproduced
Reproduced, partly reproduced or not reproduced
  1. The reader opens the PDF page by page and marks the result tables and the method sections.
  2. It writes a claim contract: the number to check, where it is, a tolerance fixed before any run, and every detail the paper leaves open.
  3. The router checks what the authors released and the planner lays out the files, one config and a smoke test. The implementer writes the code without seeing the paper's value.
  4. The code runs in a sandbox until one command re-creates the number. A repair manager steps in when it gets stuck.
  5. The verifier deletes the results, re-runs everything from scratch and searches the code for copied numbers.
  6. Reproduced, partially reproduced or not reproduced, decided by the clean re-run against the tolerance fixed in the claim contract.
